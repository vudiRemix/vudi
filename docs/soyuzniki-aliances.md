# Союзники Aliances

## Союзники в бою

Если своих сил не хватает — можно позвать на помощь дружественный город. Механика одинаковая для войны, СВО и рейда, отличаются только условия, когда это разрешено.

_Все цифры ниже — значения по умолчанию, администрация сервера может их менять._

### Кто может стать союзником

Союзником можно призвать только город, состоящий с вами в **одном альянсе** (не пакт о ненападении — это другие отношения). Город, уже участвующий в конфликте с любой стороны, призвать нельзя.

### Что происходит после призыва

* Онлайн-жители призванного города участвуют в PvP наравне с исходной стороной — их убийства и смерти считаются в очки точно так же.
* Союзник **не может** ставить/ломать флаги захвата.
* У каждой стороны — только один союзник одновременно.

### Как призвать

* Война: `/t war ally invite <город>`
* СВО: `/t svo ally invite <город>`
* Рейд: `/raid ally invite <город>`

Приглашение стоит **1000** (списывается сразу) и действует **5 минут** — если приглашённый мэр не ответит, деньги возвращаются автоматически. Ответ: `... ally accept` / `... ally deny` в соответствующей команде. При отказе деньги тоже возвращаются сразу.

### Ограничения по типу конфликта

* **Война** — в любой момент боевой фазы, без ограничений.
* **СВО** — только через **1 час** после начала боевой фазы. Если к этому моменту разрыв очков войны превышает **10:1** — звать может только проигрывающая сторона.
* **Рейд** — во время активной боевой фазы.

### Призыв по праву единой нации

Если манифест вашей нации — **«Единая нация»** (см. статью «Манифест нации»), король может призвать другой город своей нации напрямую — бесплатно, без альянса и без согласия цели:

* Война: `/t war ally conscript <город>`
* СВО: `/t svo ally conscript <город>`
* Рейд: `/raid ally conscript <город>`
