# 🔫 Военная слава

### Военная слава

Слава — очки города за победы в рейдах и войнах. От славы зависит ранг города, а ранг даёт постоянные бонусы к показателям.

* `/t glory` — слава и ранг вашего города.
* `/t glory top` — лучшие города сервера.

_Все цифры ниже — значения по умолчанию, администрация сервера может их менять._

#### Как получить и потерять славу

| Событие                                       | Слава |
| --------------------------------------------- | :---: |
| Рейд выигран (чанк отравлен)                  |  +30  |
| Город пал в рейде                             |  −15  |
| Защитники выстояли, пока не вышло время рейда |  +20  |
| Атакующие провалили рейд                      |  −10  |
| Захват казны или склада в рейде               |   +5  |
| Убийство врага в рейде (до 10 за рейд)        |   +2  |
| Победа в войне                                |  +60  |
| Поражение в войне                             |  −30  |
| Захват мирового чуда                          |  +20  |
| Потеря мирового чуда                          |  −10  |
| Боевое ежедневное задание жителя              |   +1  |

Каждый игровой день вся слава затухает на **3%**, поэтому ранг надо поддерживать.

#### Ранги

| Ранг        | Слава от | Бонусы                                                   |
| ----------- | :------: | -------------------------------------------------------- |
| Ополчение   |     0    | —                                                        |
| Гарнизон    |    100   | цена рейда −5%                                           |
| Легион      |    300   | цена рейда −10%, стабильность +5, решение «Парад победы» |
| Гвардия     |    700   | цена рейда −15%, стабильность +10, военная мощь +5       |
| Непобедимые |   1500   | цена рейда −20%, стабильность +15, военная мощь +10      |

Бонусы ранга входят в показатели города (см. «Показатели и решения города»).
