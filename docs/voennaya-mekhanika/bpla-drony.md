# БПЛА (дроны)

На сервере доступны управляемые дроны двух типов — **камикадзе** (взрываются при контакте с целью) и **разведчики** (используются для разведки территории без урона). Чтобы открыть меню крафта дрона следует написать /dronecraft и иметь здание Военный завод

***
