# ChestShop

### ChestShop — магазины на сундуках

#### Покупка и продажа

Процесс торговли через ChestShop простой:

* **ПКМ (правая кнопка мыши)** — вы **покупаете** товар
* **ЛКМ (левая кнопка мыши)** — вы **продаёте** товар

Если на счету недостаточно денег, товар закончился или сундук переполнен — об этом напишут в чат.

***

#### Как создать магазин

1. Поставьте **сундук** и **табличку** на него в удобном месте.
2. Заполните табличку по строкам:

| № строки | Содержимое        | Описание                                   |
| -------- | ----------------- | ------------------------------------------ |
| 1        | _оставить пустой_ | сюда автоматически впишется ваш ник        |
| 2        | количество        | сколько товара продаётся/покупается за раз |
| 3        | цена              | формат: `B [цена] : S [цена]`              |
| 4        | название товара   | на английском или по ID                    |

**Формат цены на строке 3:**

* `B 0.2 : S 0.1` — можно и купить, и продать (Buy / Sell)
* `B 0.2` — товар доступен только для покупки

> ID предмета можно узнать через **HMI** в лаунчере — нажмите на шестерёнку в нижнем правом углу и выберите соответствующую функцию.

***

#### Пример создания магазина

| № строки | Текст            | Описание                           |
| -------- | ---------------- | ---------------------------------- |
| 1        | _(пусто)_        | строка с ником владельца           |
| 2        | `16`             | количество товара за сделку        |
| 3        | `B 0.5 : S 0.25` | покупаем за 0.25₴, продаём за 0.5₴ |
| 4        | `RAILS`          | сам товар — рельсы                 |
