# 💰 Заработок

## Где брать деньги

*Все цифры ниже — значения по умолчанию, администрация сервера может их менять. Экономика обновлена 29.09.2026.*

### Зарплата за онлайн

Каждый час, который вы **реально играете**, на счёт приходит **3₸**. AFK не считается: минута засчитывается, если за последние 5 минут вы хоть раз крутили камерой, писали в чат, вводили команду, ломали или ставили блок, кликали в инвентаре. Накопленные минуты не сгорают при выходе с сервера.

### Работы (`/jobs`)

Оплата работ удвоена. Сколько платят на нулевом уровне и выше:

| Работа   | Что оплачивается                                                                 |
| -------- | -------------------------------------------------------------------------------- |
| Шахтёр   | уголь 0,50₸ за 4 шт., железо 1,40₸ за 4, алмазы 6₸ за 6, золото 8₸ за 6, изумруды 14₸ за 6 |
| Лесоруб  | дуб 0,40₸ за 32, берёза 0,80₸, акация 1,20₸, тёмный дуб 1,60₸, ель 2₸ за 32       |
| Фермер   | пшеница 0,30₸ за 32, картошка 0,60₸, морковь 0,80₸, свёкла 1₸ за 32               |
| Рыбак    | рыба 0,40₸, хлам 0,20₸, сокровище 0,80₸ за штуку                                  |
| Охотник  | курица 0,80₸ за 8, кролик 2₸, корова/свинья/овца 3₸, паук/скелет/зомби 4₸ за 8    |
| Головорез | как раньше: платит заказчик контракта                                           |

Более дорогие ресурсы открываются с уровнем работы.

### Скупщик (`/скупщик`)

Дороже всего скупщик платит за то, что добывается руками. Примеры цен за штуку:

| Ресурс                 | Цена   |
| ---------------------- | ------ |
| Алмаз                  | 2₸     |
| Золотой слиток         | 0,5₸   |
| Железный слиток        | 0,2₸   |
| Медный слиток          | 0,1₸   |
| Уголь                  | 0,1₸   |
| Лазурит                | 0,08₸  |
| Любое бревно           | 0,1₸   |
| Картошка, морковь      | 0,1₸   |
| Пшеница                | 0,06₸  |
| Сахарный тростник      | 0,04₸  |

Блоки из ресурсов стоят чуть меньше, чем 9 ресурсов по отдельности, так что крафт в блоки выгоды не даёт. То, что обычно фармят автофермы (бамбук, кактус, ламинария, тыквы, арбузы), стоит дёшево. Скупщик принимает и сырую руду, мясо, рыбу, дроп мобов и строительные блоки.

Следите за **горячими товарами** и **живым рынком** у скупщика: там цена бывает в несколько раз выше обычной.

### Прочее

* Ежедневные задания `/t task` — 15–80₸ за задание, ещё 25₸ за все задания дня.
* Монетный двор приносит городу деньги каждый час, пока в городе кто-то играет.

## На что уходят деньги города

* **Содержание строя** — **8₸** за каждый час, когда в городе кто-то онлайн (форма правления и идеология меняют эту сумму в процентах).
* **Содержание зданий** — раз в день вместе с налогом Towny. Сумма видна в меню каждого здания; с 29.09.2026 она вдвое меньше прежней.
* **Налог нации** — процент казны города раз в день, но **не больше 150₸** с одного города.

Держите в казне запас на содержание: если в новый день городу нечем заплатить Towny, город может быть удалён.
