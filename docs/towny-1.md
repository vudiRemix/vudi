# 🏰 Город

### Towny — основная информация

**Towny** — основа сервера, и для комфортной игры с ним обязательно нужно разобраться. На сервере можно создать собственный город либо вступить в город другого игрока. Список основных команд — в конце статьи.

***

#### Вступление в существующий город

* `/t ask` — подать заявку о том, что вы ищете город. Мэры увидят сообщение и могут пригласить вас.
* `/t online [Город]` — посмотреть, кто из жителей понравившегося города сейчас онлайн, чтобы попросить приглашение.
* `/msg [Ник] [сообщение]` — написать жителю города в личные сообщения.
* `/t leave` — выйти из города.

***

#### Деньги

Для создания города нужны ресурсы, а для дальнейшего развития — деньги. Ежедневно с города списывается налог, который растёт с каждым новым чанком: **1 чанк =** +5₸ **к налогу**.

Способы заработка описаны в гайде **«Как играть»**.

* `/bal` или `/money` — проверить свой баланс.

***

#### Создание города

Создавать город в одиночку не рекомендуется — лучше сразу собрать команду единомышленников, готовых вступить сразу после основания.

```
/town new [Название]
```

Максимальная длина названия города (и нации) — **18 символов**.

**Ресурсы для создания города:**

| Ресурс         | Количество |
| -------------- | ---------- |
| Булыжник       | 256        |
| Доски          | 128        |
| Дуб (бревно)   | 64         |
| Железный меч   | 2          |
| Железная кирка | 1          |
| Печь           | 2          |
| Верстак        | 1          |
| Стекло         | 32         |

> **Важно:** сразу пополните городскую казну командой `/t deposit [сумма]` — иначе город удалят на следующий день из-за нехватки средств.

* `/towny time` — узнать время до следующего снятия налогов.
* `/t invite [Никнейм]` — пригласить игрока в город.

***

#### Настройка города

Главное меню настроек: `/t menu`

**Уровни доступа игроков**

**Для личных участков:**

| Уровень  | Описание      |
| -------- | ------------- |
| FRIEND   | друзья        |
| TOWN     | жители города |
| ALLY     | союзники      |
| OUTSIDER | посторонние   |

**Для общих (не личных) участков:**

| Уровень  | Описание             |
| -------- | -------------------- |
| RESIDENT | жители города        |
| NATION   | жители нации         |
| ALLY     | жители союзных наций |
| OUTSIDER | посторонние          |

**Общие настройки города**

| Параметр     | Что регулирует                         |
| ------------ | -------------------------------------- |
| `PVP`        | пвп в городе                           |
| `MOBS`       | спавн мобов                            |
| `EXPLOSION`  | взрывы                                 |
| `OPEN`       | вступление в город без приглашения     |
| `FIRE`       | распространение огня                   |
| `TAXPERCENT` | процентный налог вместо фиксированного |

Использование: `/t toggle [параметр]` — например, `/t toggle pvp` Аналогично работает для участков: `/plot toggle [параметр]`

**Настройки доступа (права)**

| Параметр  | Что разрешает                                       |
| --------- | --------------------------------------------------- |
| `SWITCH`  | взаимодействие с сундуками, механизмами             |
| `ITEMUSE` | использование предметов (ведро лавы, огниво и т.п.) |
| `DESTROY` | разрушение блоков                                   |
| `BUILD`   | строительство                                       |

Использование:

```
/t set perm [уровень доступа] [параметр] on/off
```

Аналогично для участков: `/plot set perm ...`

**Пример:** `/t set perm outsider switch off` — запретить посторонним открывать сундуки.

***

#### Личные участки

Участок — это чанк 16×16. Границы чанков удобно смотреть комбинацией клавиш **F3+G**.

**Создание участка:**

1.  Мэр, ассистент или советник создаёт участок и выставляет его на продажу:

    ```
    /plot forsale [цена]
    ```
2.  Житель встаёт на нужный чанк и пишет:

    ```
    /plot claim
    ```

    Деньги с его баланса уйдут в казну города, и участок закрепится за ним. На участке не сможет ничего делать никто, кроме владельца, мэра и игроков со званиями Советник, Ассистент и Доверенный.

**Как дать другу доступ к сундукам на своём участке:**

1. `/res friend add [никнейм]` — добавить игрока в друзья
2. `/plot set perm friend [параметр] on/off` — выдать нужное право

> `/res friend remove [никнейм]` — удалить друга `/res friend list` — посмотреть список друзей

***

#### Типы участков

| Тип       | Описание                                                                                          |
| --------- | ------------------------------------------------------------------------------------------------- |
| `SHOP`    | магазин                                                                                           |
| `EMBASSY` | посольство — после выставления на продажу его может купить игрок из другого города                |
| `FARM`    | ферма — даже при запрете строительства/разрушения сбор урожая и посадка культур остаются доступны |
| `ARENA`   | арена                                                                                             |

Использование: `/plot set [тип]`
