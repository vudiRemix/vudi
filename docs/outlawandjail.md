# Розыск и тюрьмы (t jail t outlaw)



Система для городов, которые хотят наказывать преступников — своих же жителей или чужаков, пойманных на своей территории. Состоит из двух частей: объявление в розыск (`/t outlaw`) и физическая тюрьма (её строит и обслуживает сам город через обычные Towny-плоты).

### Как попасть в розыск

Мэр или советник города объявляет игрока в розыск:

```
/t outlaw add <ник>
```

В розыск можно объявить как чужака, так и своего же жителя — во втором случае **из города вас больше не выкинет**. Розыск не мешает жить в городе как обычно, пока преступника не поймают.

Снять розыск (простить):

```
/t outlaw remove <ник>
```

> Прощение сразу освобождает преступника из тюрьмы, если он сидит именно за это (даже если он не в сети), и отменяет награду за его голову, если она была назначена — деньги возвращаются в казну.

### Что грозит преступнику

Пока вы в розыске, особые правила действуют на территории города, который вас разыскивает, **и всей его нации** — это происходит автоматически. На территории **союзников** это тоже сработает, но только если между городами заключён **договор о передаче преступников** (см. ниже) — сам по себе союз больше не даёт этого права.

* **Свечение.** Преступника видно издалека — он светится, пока стоит на этой территории.
* **PvP всегда включено.** Не важно, что стоит на городе/нации — против преступника драться можно всегда. **Ответный удар:** если преступника ударили, он может 20 секунд бить в ответ, пока идёт бой, но только тех, кто обязан ловить преступников: мэра, советника, депутата, чиновника и полицейского. Случайных прохожих преступник задеть не может. Пока идёт это окно, на преступника действуют **Слабость III** и **Скорость III** — он может убегать, но не может устроить резню.
* **Оповещение жителям.** Когда преступник заходит на территорию, город получает сообщение об этом в чат.
* **Смерть = тюрьма.** Если преступника убили на этой территории — он отправляется в тюрьму, а город получает отдельное сообщение о поимке.

#### Арест без убийства

`/t outlaw arrest <ник>` — задержать преступника мирно. Он должен стоять вплотную к вам (до 4 блоков), быть на территории, где он в розыске, и сейчас **не драться**. Если он в бою, поймать его можно только прежним способом: убить. Арестовать может любой игрок.

#### Кто кого разыскивает

* `/t outlaw wanted` — все преступники в зоне вашего города (город, нация и союзники) и кто именно их объявил.
* `/t outlaw info <ник>` — награда, срок и статус конкретного преступника.
* `/t outlaw where <ник>` — у каких городов **всего сервера** игрок в розыске, с наградами, и сидит ли он сейчас.

**Договор о передаче преступников**

Чтобы форс-PvP против преступника действовал ещё и на территории союзника, одного союза недостаточно — нужен отдельный договор, на который должны согласиться **обе стороны**:\
/t outlaw treaty propose <город> — предложить договор союзнику\
/t outlaw treaty accept <город> — принять предложение (принимает та сторона, которая НЕ предлагала)\
/t outlaw treaty cancel <город> — разорвать договор или отменить предложение, в любой момент, без согласия другой стороны\
/t outlaw treaty list — список всех договоров и предложений вашего города\
Предложить договор можно только тому, кто уже является союзником. Обе стороны получают сообщение в чат при предложении, принятии и разрыве договора.

#### Тюрьма

Пока преступник сидит:

* **Нельзя пользоваться вообще никакими командами** — ни чтобы сбежать, ни чтобы позвать на помощь.
* **Нельзя телепортироваться** — ни эндер-жемчугом, ни хорусом, ничем.
* Срок отсчитывается в реальном времени, даже если вы вышли с сервера.
* Если попробовать выйти за пределы тюрьмы пешком — вернёт обратно.
* По истечении срока — освобождение автоматическое.

#### Как мэру устроить тюрьму

Ничего специально настраивать не нужно — тюрьма собирается из обычных плотов города с типом `Jail`, как и раньше в Towny:

```
/plot set jail
```

Несколько плотов **вплотную друг к другу** (по стороне, не по диагонали) автоматически объединяются в одну тюрьму — можно строить сколько угодно большую территорию.

> Плоты `Jail`, которые стоят **рядом, но не вплотную** — то есть ближе, чем на 20 чанков, но и не соприкасаются — создать не получится. Игра предупредит: либо присоединяйте новый чанк вплотную к уже существующей тюрьме, либо отходите дальше и стройте отдельную. Это чтобы тюрьмы города не расползались хаотично на пол-карты мелкими обрубками.

#### Отдельные камеры (для тех, кто строит красиво)

Если хотите не просто общую площадку, а тюрьму с настоящими камерами и коридором для надзирателей — зарегистрируйте отдельные точки внутри тюрьмы:

```
/mjail prcell <тюрьма> new     — стоя в нужном месте, регистрирует новую камеру
/mjail prcell <тюрьма> list    — список камер
/mjail prcell <тюрьма> remove <номер> — убрать камеру
```

Каждая камера подписана голограммой с номером. Как только у тюрьмы есть хотя бы одна зарегистрированная камера, каждый новый преступник садится в первую свободную — если все заняты, идёт на общую точку тюрьмы. Стены и коридоры между камерами — уже ваша постройка, игра их не проверяет, только запоминает, куда телепортировать.

### Срок заключения

По умолчанию — 1 час. Мэр/советник может заранее назначить конкретный срок для конкретного преступника — сработает, когда его поймают:

```
/t outlaw punishment <ник> <секунды>
```

Максимум — 10 часов (36000 секунд).

### Награда за голову

Мэр/советник может назначить награду городской казной за поимку преступника:

```
/t outlaw bounty_on <ник> <сумма>
```

Сумма списывается из казны сразу, в момент назначения. Если преступника убьют (не важно, кто — житель, союзник или просто оказавшийся рядом игрок), убийца автоматически получает деньги на баланс.

Передумали — награду можно отменить, деньги вернутся в казну:

```
/t outlaw bounty_cancel <ник>
```

> Отменяет только награду вашего города. Если на ту же голову назначили награду ещё и союзники — их награда остаётся активной, вы отменяете только свою.

### Роль Полицейский

Городская роль `POLICEMAN` (выдаётся как и остальные городские роли) раз в минуту получает сообщение с координатами преступников, находящихся в зоне розыска города.

> Роль не даёт прав что-то ещё, кроме получения этих сообщений — задерживать преступника всё равно нужно обычным способом (убить на территории).

### Коротко: что нужно помнить

| Действие                        | Кто может       | Команда                                |
| ------------------------------- | --------------- | -------------------------------------- |
| Объявить в розыск               | Мэр, советник   | `/t outlaw add <ник>`                  |
| Простить (снять розыск)         | Мэр, советник   | `/t outlaw remove <ник>`               |
| Назначить срок заранее          | Мэр, советник   | `/t outlaw punishment <ник> <секунды>` |
| Назначить награду               | Мэр, советник   | `/t outlaw bounty_on <ник> <сумма>`    |
| Отменить награду                | Мэр, советник   | `/t outlaw bounty_cancel <ник>`        |
| Разметить тюрьму                | Мэр             | `/plot set jail` (как обычно)          |
| Завести камеру                  | Мэр             | `/mjail prcell <тюрьма> new`           |
|  Предложить договор с союзником |  Мэр, советник  | `/t outlaw treaty propose <город>`     |
| Принять договор                 | Мэр, советник   | `/t outlaw treaty accept <город>`      |
| Разорвать договор               | Мэр, советник   | `/t outlaw treaty cancel <город>`      |
