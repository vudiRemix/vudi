# Национальные квесты

### Квесты нации

Прогресс нации наполняют **все** жители **любого** её города, а не только столицы.

_Все цифры ниже — значения по умолчанию, администрация сервера может их менять._

#### Вклад

* `/n quest contribute money [сумма]` — деньгами. Курс **500₸ = 1 очко**, лимит **20 очков в день** на нацию.
* `/n quest contribute ore [количество]` — ресурсом из руки, свой отдельный лимит **20 очков в день**.

Если не указать сумму или количество, вносится максимум в пределах оставшегося дневного лимита. Оба лимита сбрасываются каждый игровой день.

Сколько очков даёт ресурс:

| Ресурс                             | Очков за штуку |
| ---------------------------------- | :------------: |
| Каменный кирпич, бумага            |      0.005     |
| Глубинносланцевый кирпич           |      0.008     |
| Уголь, редстоун                    |      0.02      |
| Медный слиток, лазурит             |      0.03      |
| Книжная полка                      |      0.04      |
| Железный слиток, динамит, обсидиан |      0.05      |
| Золотой слиток                     |       0.1      |
| Изумруд                            |       0.3      |
| Железный блок                      |      0.45      |
| Алмаз                              |       0.5      |
| Золотой блок                       |       0.9      |
| Незеритовый слиток                 |        3       |
| Алмазный блок                      |       4.5      |

#### Обмен на деньги

`/n quest redeem` — только король. Переводит **все** накопленные очки в деньги в **казну нации** по курсу **300₸ за очко**.

#### Посмотреть прогресс

`/n quest` без аргументов показывает накопленные очки и сколько ещё можно внести сегодня.
