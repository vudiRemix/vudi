# 🗝️ Регистрация

### Регистрация и вход

Играть на сервере **MANULCRAFT** можно без покупки лицензии Minecraft.

#### Как начать игру

1. **Установите лаунчер** — подойдёт любой (Legacy Launcher, TLauncher и др.)
2. **Версия** — запускайте версию 1.19+ (рекомендуется **1.21.4**)
3. **OptiFine** — обязательно установите OptiFine для корректной работы ресурс-пака с оружием и интерфейсом
4. **IP адрес** — `manulcraft.com`

#### Регистрация аккаунта

При первом входе на сервер введите команду:

```
/register [Пароль] [Повтор пароля]
```

При последующих заходах используйте:

```
/login [Пароль]
```

> **Важно:** Если система пишет, что ник занят, смените его в настройках вашего лаунчера. Если при входе требует пароль, а вы не регистрировались — значит, никнейм уже кем-то используется.
