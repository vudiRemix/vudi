# Выращивание

<figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

<mark style="color:blue;">**Выращивание**</mark> - самый простой способ, но и самый долгий для получения веществ. Выращивать можно **на пашне**, по старинке, и в специальном механизме **Гроубокс.**

Для выращивания вам потребуются семена и разрешение. Некоторые из них выпадают с травы, а другие покупаются у картеля.

### <mark style="color:blue;">Вы</mark><mark style="color:blue;">**ращивание через пашню**</mark>

Через пашню выращиваются:

* **Кока**
* **Опиум**
* **Афганка**
* **Табак**

Чтобы подготовить место для посадки, вспахайте землю мотыгой и сделайте источник воды.\
Семенами кликните по пашне и ожидайте, пока вырастит. Кликнув ПКМ по растению, можно увидеть стадию роста и готово ли оно к сбору.

{% hint style="info" %}
Чтобы собрать растение, нужны ножницы
{% endhint %}

<figure><img src="../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>

Через гроубокс выращивается сортовой каннабис: _**OGKUSH, WhiteWidow, AK47, PURPLERIDER**_\
Гроубокс приобрести можно у картеля.

### <mark style="color:blue;">Выращивание через гроубокс</mark>

<figure><img src="../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>

После приобретения поставьте гроубокс и нажмите по нему. В слот с пашней переместите семена, чтобы посадить куст.

**Теперь нужно позаботиться&#x20;**<mark style="color:blue;">**о поливе**</mark><mark style="color:blue;">.</mark> Ведром нажмите по посаженному кусту, чтобы полить его. Если вы не поливаете растение - оно засыхает и помирает. Также, куст не начнет расти, пока вы не польете его.

Как куст вырос, а вы это поймете по модельке, нажмите по нему, чтобы собрать шишки. Собрать шишки можно только имея <mark style="color:yellow;">**ножницы в инвентаре**</mark>

{% hint style="success" %}
Кликнув часами по гроубоксу, можно узнать информацию по нему: _Уровень полива, Качество куста и добавленные добавки._
{% endhint %}

<figure><img src="../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure>

#### <mark style="color:blue;">Добавки</mark>

Приобрести можно их у картеля.

Всего есть 3 добавки, которые можно добавить в куст:

* **Ускоритель роста.** Повышает скорость роста на 30%, но при этом качество максимальное будет доступно _Стандартное_
* **Удобрение.** Повышает качество до _стандартного._
* **Химудобрение**. Повышает урожай на 50%, но при этом качество остается _низким._ Повысить нельзя.

#### <mark style="color:blue;">Качества</mark>

**Качества для сортовой марихуаны.** Афганка имеет максимально низкое качество.

{% tabs %}
{% tab title="Низкое" %}
Доступно с ранга **ДИЛЕТАНТ**

**Низкое качество влияет на:**

* Шанс поймать **передозировку 25%**
{% endtab %}

{% tab title="Стандартное" %}
Доступно с ранга **УЧЕНИК**

**Стандартное качество влияет на**~~**:**~~

* Снижение времени **негативных** эффектов на 15%
* С **шансом 5%** может не повысить толерантность или зависимость
* Дополнительный балл к эффекту
* Шанс поймать **передозировку 5%**
{% endtab %}

{% tab title="Высокое" %}
Доступно с ранга **ГРОВЕР**

**Высокое качество влияет на:**

* Снижение времени **негативных** эффектов на 25%
* Время положительных эффекты повышается на 10%
* С **шансом 15%** может не повысить толерантность или зависимость
* Дополнительные 2 балла к эффекту
* Шанс 70%, что не будет отходов после эффекта.
* Шанс не поймать **передозировку 30%**
{% endtab %}

{% tab title="Легендарное" %}
Доступно с ранга **КУЛЬТИВАТОР**

**Высокое качество влияет на:**

* Снижение времени **негативных** эффектов на 35%
* Время положительных эффекты повышается на 20%
* С **шансом 25%** может не повысить толерантность или зависимость
* Дополнительные 3 балла к эффекту
* Шанс 90%, что не будет отходов после эффекта.
* Шанс не поймать **передозировку 40%**
{% endtab %}
{% endtabs %}

#### <mark style="color:blue;">**Сушилка**</mark>

Сушилка нужна, чтобы высушить табак или повысить качество марихуаны.\
**Её можно приобрести у картеля.**

После приобретения, поставьте ее. Разместите в жёлтых слотах то, что будете сушить.\
Сушка длиться 30 минут, после чего повышается качество или вы получаете высушенное лекарство. Чтобы еще раз поднять качество, положите еще раз сушиться.

<figure><img src="../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>

#### &#x20;<mark style="color:blue;">РАНГИ ГРОВЕРСТВА МАРИХУАНЫ</mark>

Ранг дает доступ к новым сортам и доступ к качествам. Чтобы повысить ранг, сушите и собирайте урожай или продавайте картелю товар, за это вам начисляются очки.

Чтобы **узнать** свой ранг, напишите <kbd>/drugs</kbd> и выберите <mark style="color:blue;">"Ранги"</mark>

{% hint style="info" %}
Дилетант - ранг, с которого начинают все
{% endhint %}
