# Синтезирование и варка

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

Изготовление синтетических лекарств разделяется на 2 вида:

1. <mark style="color:blue;">**Варка:**</mark> используется специальный механизм котёл, который приобретается у картеля. Через него можно создать ингредиенты для дальнейшего синтезирования. Например, паста коки или реагенты.
2. <mark style="color:blue;">**Синтезирование:**</mark> используется Лаборатория, приобретается у картеля. Через неё можно нагревать и кристаллизировать, получая вещества.

Для производства синтетических лекарств вам потребуется **покупка лицензии** у картеля

{% hint style="info" %}
Качество и чистота сваренного продукта зависит от вашего ранга. Чем выше ранг, тем лучше продукт.
{% endhint %}

### <mark style="color:blue;">Качества</mark>

**Качества сваренных продуктов.** Для каждого синтетического и полусинтетического продукта свое качество.

{% tabs %}
{% tab title="Низкое" %}
Доступно с ранга **0 LvL**

**Доступная чистота:** 15-50%

**Низкое качество влияет на:**

* Шанс поймать **передозировку 25%**
{% endtab %}

{% tab title="Стандартное" %}
Доступно с ранга **1 LvL**

**Доступная чистота:** 50-80%

**Стандартное качество влияет на**~~**:**~~

* Снижение времени **негативных** эффектов на 15%
* С **шансом 5%** может не повысить толерантность или зависимость
* Дополнительный балл к эффекту
* Шанс поймать **передозировку 5%**
{% endtab %}

{% tab title="Высокое" %}
Доступно с ранга **2 LvL**

**Доступная чистота:** 80-90%

**Высокое качество влияет на:**

* Снижение времени **негативных** эффектов на 25%
* Время положительных эффекты повышается на 10%
* С **шансом 15%** может не повысить толерантность или зависимость
* Дополнительные 2 балла к эффекту
* Шанс 70%, что не будет отходов после эффекта.
* Шанс не поймать **передозировку 30%**
{% endtab %}

{% tab title="Легендарное" %}
Доступно с ранга **3 LvL**

**Доступная чистота:** 90-99.9%

**Высокое качество влияет на:**

* Снижение времени **негативных** эффектов на 35%
* Время положительных эффекты повышается на 20%
* С **шансом 25%** может не повысить толерантность или зависимость
* Дополнительные 3 балла к эффекту
* Шанс 90%, что не будет отходов после эффекта.
* Шанс не поймать **передозировку 40%**
{% endtab %}
{% endtabs %}

### <mark style="color:blue;">Механизмы</mark>

Кликните по блоку, чтобы поставить механизм. Если хотите его убрать, то ударьте по нему. Все механизмы приобретаются у Картеля.

Механизмы **требуют топливо** для работы. Доступное топливо:

* Уголь
* Блок угля
* Ведро лавы
* Все виды досок
* Все виды дерева (LOG и WOOD)

{% hint style="warning" %}
Когда вы начинаете работу с механизмами, вам необходимо надеть **Химкостюм**. Приобретается у картеля. С каждой варкой он портиться и вам нужно покупать новый.

**Если вы начнете варить без химзащиты, вы начнёте задыхаться и умрёте :)**
{% endhint %}

#### <mark style="color:blue;">Котёл</mark>

В нём варятся ингредиенты **для синтезирования** а также реагенты. Чтобы начать в нём варить, поместите ингредиенты в слоты.

**Ниже и на скриншоте объяснил, что и куда ложить:**

* **Жёлтые слоты:** сюда ингредиенты
* **Красный слот:** сюда топливо
* **Зелёный слот:** тут выходит сваренное изделие

<figure><img src="../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>

#### <mark style="color:blue;">Лаборатория</mark>

В ней синтезируются реагенты и ингредиенты. Чтобы сварить, требуется выбрать вид варки: **Нагревание** или **Кристаллизация**

**Ниже и на скриншоте объяснил, что и куда ложить:**

* **Жёлтые слоты:** сюда ингредиенты
* **Красный слот:** сюда топливо
* **Фиолетовый слот:** выбрать кристаллизацию
* **Оранжевый слот:** выбрать нагревание
* **Зелёный слот:** тут выходит сваренное изделие
