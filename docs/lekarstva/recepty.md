## Рецепты

В этом разделе написаны рецепты всех лекарств более подробно. Для вашего удобства мы разделили рецепты на 3 категории: **Натуральные, Полусинтетические, Синтетические**

{% hint style="info" %}
Если вам нужно найти определенный предмет, ищите по ключевому слову. Используйте сочетание клавиш **CTRL + F** и введите слово, например **"Метамфетамин"**
{% endhint %}

### <mark style="color:blue;">**НАТУРАЛЬНЫЕ**</mark>

* Выращиваются через **гроубокс** или **пашню.**
* Семена приобретаются **у картеля.**
* Повысить качество можно через **сушилку**

#### <mark style="color:blue;">МАРИХУАНА</mark>

Дополнительная информация в разделе **Выращивание**\
Доступные сорта: **Афганка, OGKUSH, WhiteWidow, AK47, PURPLERIDER**

{% stepper %}
{% step %}
#### Выращивание

Посадите семена в гроубокс или на Пашню. Как куст вырос, соберите урожай
{% endstep %}

{% step %}
#### Урожай

Если вам безразлично на качество, употребить марихуану можно скрафтив косяк. В разделе "Крафты" показали как крафтить
{% endstep %}

{% step %}
#### Сушилка

Если вы хотите повысить качество, используйте сушилку для этого. Как вы подняли необходимое качество, можете скрафтить косяк.
{% endstep %}
{% endstepper %}

#### <mark style="color:blue;">ГАШИШ</mark>

Дополнительная информация в разделе **Кирпичный пресс**\
Доступные печати: **Manul Ferruginea, PAKISTAN**

{% stepper %}
{% step %}
#### Выращивание

Посадите семена марихуаны в гроубокс.

* для **Manul Ferruginea** требуется сорт **OGKUSH**
* для **PAKISTAN** требуется сорт **PURPLERIDER**
{% endstep %}

{% step %}
#### Урожай

Соберите урожай с кустов, качество гашиша зависит от качества травы. Если хотите качественный гашиш, в Сушилке повысьте качество травы.
{% endstep %}

{% step %}
#### Пресс

Приобретите лицензию у картеля на гашиш и приобретите кирпичный пресс. Выложите нужные шишки в слоты и нажмите кнопку пресса.
{% endstep %}

{% step %}
#### Использование

Плитку гашиша переместите в пресс. Вы получите ляпки. Скрафтите булик (в Разделе Крафты показан крафт), добавьте к нему сигарету и ляпку. После чего нажмите ПКМ для употребления.
{% endstep %}
{% endstepper %}

{% step %}
#### Сушилка

### <mark style="color:blue;">**ПОЛУСИНТЕТИЧЕСКИЕ**</mark>

* Ингредиенты выращиваются **на пашне.**
* Семена приобретаются **у картеля.**
* Для варки требуются механизмы.

{% hint style="warning" %}
Чтобы начать варить, приобретите лицензию у картеля на определенные вещества.
{% endhint %}

#### <mark style="color:blue;">КОКАИН</mark>

Дополнительная информация по выращиванию в разделе **Выращивание**\
Дополнительная информация по синтезу и варке в разделе **Синтезирование и варка**

{% stepper %}
{% step %}
#### Выращивание

Посадите семена коки на пашню
{% endstep %}

{% step %}
#### Варка

Как кока выросла, соберите урожай с куста. Добавьте в Котёл <kbd>6 шт. Листьев Коки</kbd> и <kbd>1 шт. Канистра бензина.</kbd> После варки получается **Кокаиновая паста**
{% endstep %}

{% step %}
#### Лабораторная печь

Поместите **Кокаиновая паста** в лабораторную печь и ожидайте
{% endstep %}
{% endstepper %}

#### <mark style="color:blue;">КРЭК</mark>

Дополнительная информация по выращиванию в разделе **Выращивание**\
Дополнительная информация по синтезу и варке в разделе **Синтезирование и варка**

{% stepper %}
{% step %}
#### Выращивание

Посадите семена коки на пашню
{% endstep %}

{% step %}
#### Варка

Как кока выросла, соберите урожай с куста. Добавьте в Котёл <kbd>6 шт. Листьев Коки</kbd> и <kbd>1 шт. Канистра бензина.</kbd> После варки получается **Кокаиновая паста**
{% endstep %}

{% step %}
#### Лаборатория

Поместите **Кокаиновая паста** в лабораторию и выберите **Нагрев.** После получения <kbd>Жидкого крэка</kbd> выберите **Кристаллизацию**
{% endstep %}
{% endstepper %}

#### <mark style="color:blue;">ГЕРОИН</mark>

Дополнительная информация по выращиванию в разделе **Выращивание**\
Дополнительная информация по синтезу и варке в разделе **Синтезирование и варка**

{% stepper %}
{% step %}
#### Выращивание

Посадите семена опиумного мака на пашню
{% endstep %}

{% step %}
#### Варка

Как мак выросл, соберите урожай с цветка. Добавьте в Котёл <kbd>3шт. Опиума</kbd> <kbd>1 шт. Ведро воды</kbd> <kbd>1 шт Фенилэтиламин</kbd> После варки получается **Вываренный опиум**
{% endstep %}

{% step %}
#### Синтезатор кристаллов

Поместите **Вываренный опиум** в синтезатор кристаллов. Заморожьте до состояния **Замороженный Опиум I** и повторите процедуру, чтобы получить **Замороженный Опиум II**
{% endstep %}

{% step %}
#### Лаборатория

Поместите **Замороженный Опиум II** в лабораторию и выберите **Кристаллизация**
{% endstep %}
{% endstepper %}

### <mark style="color:blue;">**СИНТЕТИЧЕСКИЕ**</mark>

* Ингредиенты покупаются у **Картеля**
* Реагенты варятся в котле
* Для варки требуются механизмы.

{% hint style="warning" %}
Чтобы начать варить, приобретите лицензию у картеля на определенные вещества.
{% endhint %}

#### <mark style="color:blue;">АМФЕТАМИН</mark>

Дополнительная информация по синтезу и варке в разделе **Синтезирование и варка**

{% stepper %}
{% step %}
#### Покупка ингредиентов

Приобретите <kbd>Люминесцентный порошок</kbd> <kbd>Изопропиловый спирт</kbd> <kbd>Ацетон</kbd> у картеля
{% endstep %}

{% step %}
#### Варка реагента

Добавьте в котёл <kbd>Ацетон</kbd> <kbd>3 шт. Костной муки</kbd> <kbd>1 шт. Ведро воды</kbd> <kbd>3 шт. Аметиста</kbd> для получения реагента **C9H13N**
{% endstep %}

{% step %}
#### Лаборатория

Поместите <kbd>реагент C9H13N</kbd> <kbd>Люминесцентный порошок</kbd> <kbd>Изопропиловый спирт</kbd> в лабораторию и кристаллизируйте 1 раз для получения **Амфетаминовые кристаллы**
{% endstep %}

{% step %}
#### Лабораторная печь

Поместите **Амфетаминовые кристаллы** в лабораторную печь
{% endstep %}
{% endstepper %}

#### <mark style="color:blue;">МЕФЕДРОН</mark>

Дополнительная информация по синтезу и варке в разделе **Синтезирование и варка**

{% stepper %}
{% step %}
#### Покупка ингредиентов

Приобретите <kbd>Ацетон</kbd> <kbd>Цефалоспирин</kbd> <kbd>Изопропиловый спирт</kbd> <kbd>Салициловая кислота</kbd> у картеля
{% endstep %}

{% step %}
#### Варка реагента

Добавьте в котёл <kbd>Ацетон</kbd> <kbd>Цефалоспирин</kbd> <kbd>3 шт. Костной муки</kbd> <kbd>1 шт. Ведро воды</kbd> для получения реагента **4MMC**

{% step %}
#### Лаборатория

Поместите <kbd>реагент 4MMC</kbd> <kbd>Изопропиловый спирт</kbd> <kbd>Салициловая кислота</kbd> в лабораторию и выберите **Нагрев** для получения **Жидкий мефедрон**

Поместите **Жидкий мефедрон** в синтезатор кристаллов для получения **Замороженный мефедрон** и повторите процедуру для получения **Мефедроновые кристаллы**
{% endstep %}

{% step %}
#### Лабораторная печь

**Мефедроновые кристаллы** поместите в печь
{% endstep %}
{% endstepper %}
